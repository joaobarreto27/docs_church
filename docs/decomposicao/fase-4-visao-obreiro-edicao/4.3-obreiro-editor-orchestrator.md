## 1. Diagnóstico e Problemas Atuais

O arquivo `src/components/obreiro/ObreiroEditor.tsx` é o maior arquivo de todo o projeto (1.682 linhas):
1. **Monolito Extremo:** Concentra lógica de scrollspy manual (`window.addEventListener('scroll')`), estado de 4 abas, 12 rascunhos em lote, preview de púlpito, modal de confirmação e mais de 1.200 linhas de formulários em JSX.
2. **Impacto na Produtividade:** A manutenção deste arquivo é lenta e complexa para qualquer engenheiro ou modelo de IA.
3. **Alto Risco de Quebras:** Qualquer ajuste pontual de layout arrisca desalinhar a barra de rolagem e os IDs de navegação.

---

## 2. Diretrizes de Arquitetura & Patterns

- **Single Responsibility (`/design-patterns`):**
  - O `ObreiroEditor.tsx` torna-se um orquestrador visual enxuto que une:
    - `useRoom()` para acesso aos dados do culto.
    - `useObreiroScrollSpy()` para rastreamento suave da seção visível.
    - `ObreiroSectionNav.tsx` para a barra de atalhos sticky.
    - Os 4 cards litúrgicos especializados (`VisitorsEditorSection`, `PrayersEditorSection`, `OpportunitiesEditorSection`, `ChoirsChecklistSection`).
- **Composition Pattern:**
  - Isolamento limpo dos modais de apoio (Prévia do Púlpito e Confirmação).

### REQUISITOS DETERMINÍSTICOS:

1. **ESTRUTURA DO NOVO `ObreiroEditor.tsx`:**
   ```typescript
   import React, { useState } from 'react';
   import { useRoom } from '../../context/RoomContext';
   import { useObreiroScrollSpy } from './hooks/useObreiroScrollSpy';
   import { ObreiroSectionNav } from './components/ObreiroSectionNav';
   import { 
     VisitorsEditorSection, 
     PrayersEditorSection, 
     OpportunitiesEditorSection, 
     ChoirsChecklistSection 
   } from './sections';

   export const ObreiroEditor: React.FC<{ showHeader?: boolean }> = ({ showHeader = true }) => {
     const { room, blocks, appendItemsToBlock, removeItemFromBlock, updateBlock, setPulpitPreviewActive } = useRoom();
     const { activeSection, scrollToSection } = useObreiroScrollSpy();

     if (!room) return null;

     const visitorsBlock = blocks.find(b => b.type === 'visitors');
     const prayersBlock = blocks.find(b => b.type === 'prayers');
     const oppsBlock = blocks.find(b => b.type === 'opportunities');
     const choirsBlock = blocks.find(b => b.type === 'choirs');

     return (
       <div className="min-h-screen bg-[#FAF8F5] pb-24 text-[#1C1917]">
         <ObreiroSectionNav 
           activeSection={activeSection} 
           onSelectSection={scrollToSection} 
         />

         <main className="max-w-4xl mx-auto px-3 sm:px-4 py-4 space-y-6">
           <VisitorsEditorSection 
             room={room}
             block={visitorsBlock}
             onAppend={appendItemsToBlock}
             onRemove={removeItemFromBlock}
           />

           <PrayersEditorSection 
             room={room}
             block={prayersBlock}
             onAppend={appendItemsToBlock}
             onRemove={removeItemFromBlock}
           />

           <OpportunitiesEditorSection 
             room={room}
             block={oppsBlock}
             onAppend={appendItemsToBlock}
             onRemove={removeItemFromBlock}
           />

           <ChoirsChecklistSection 
             block={choirsBlock}
             onUpdate={updateBlock}
           />
         </main>
       </div>
     );
   };
   ```
