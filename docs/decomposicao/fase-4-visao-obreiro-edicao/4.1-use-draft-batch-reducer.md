## 1. Diagnóstico e Problemas Atuais

No componente `ObreiroEditor.tsx`, o gerenciamento de rascunhos de digitação em lote está triplicado de forma quase idêntica:
1. **Visitantes:** `visitorBatchText`, `visitorLines`, `handleVisitorBatchTextChange`, `handleVisitorLinesChange`, `handleClearVisitorBatch`, com salvamento no `localStorage` sob a chave `docs_church_draft_visitors_${room.id}`.
2. **Pedidos de Oração:** `prayerBatchText`, `prayerLines`, `prayerUrgent`, `handlePrayerBatchTextChange`, `handlePrayerLinesChange`, `handleClearPrayerBatch`, com salvamento em `docs_church_draft_prayers_${room.id}`.
3. **Oportunidades:** `oppBatchText`, `oppLines`, `handleOppBatchTextChange`, `handleOppLinesChange`, `handleClearOppBatch`, com salvamento em `docs_church_draft_opps_${room.id}`.
4. **Problemas:** Mais de 250 linhas de código redundante apenas para sincronizar um `textarea` com um array de linhas e o `localStorage`. Qualquer alteração na lógica de parse exige mexer em 3 lugares diferentes.

---

## 2. Diretrizes de Arquitetura & Patterns

- **Reducer Pattern (`/design-patterns`):**
  - Unificar a máquina de estados de rascunho em um hook reutilizável `useDraftBatch`:
    - Estado: `{ rawText: string, lines: string[], isUrgent?: boolean }`.
    - Ações: `SET_RAW_TEXT`, `SET_LINES`, `TOGGLE_URGENT`, `CLEAR_DRAFT`.
- **Prevenção de Requisições Desnecessárias (`/secure-architecture` - Lei 6):**
  - O rascunho local é salvo puramente no `localStorage` durante a digitação. Zero tráfego de rede e zero chamadas ao banco Neon enquanto o obreiro digita a lista de visitantes da noite.
- **Resiliência:**
  - Se o navegador for recarregado acidentalmente ou o celular desligar, o texto digitado permanece preservado no `localStorage`.

### REQUISITOS DETERMINÍSTICOS:

1. **CRIAÇÃO DE `useDraftBatch.ts`:**
   ```typescript
   import { useState, useEffect, useCallback } from 'react';

   interface UseDraftBatchOptions {
     storageKey: string;
     initialUrgent?: boolean;
   }

   export function useDraftBatch({ storageKey, initialUrgent = false }: UseDraftBatchOptions) {
     const [rawText, setRawText] = useState<string>(() => {
       try {
         return localStorage.getItem(storageKey) || '';
       } catch {
         return '';
       }
     });

     const [lines, setLines] = useState<string[]>(() => {
       const initial = rawText.trim();
       return initial ? initial.split('\n') : [''];
     });

     const [isUrgent, setIsUrgent] = useState<boolean>(initialUrgent);

     // Atualiza texto bruto e recalcula linhas
     const updateRawText = useCallback((text: string) => {
       setRawText(text);
       const split = text.split('\n');
       setLines(split.length > 0 ? split : ['']);
       try {
         localStorage.setItem(storageKey, text);
       } catch {}
     }, [storageKey]);

     // Atualiza linhas (ex: pelo modal de linhas individuais) e recalcula texto
     const updateLines = useCallback((newLines: string[]) => {
       setLines(newLines);
       const joined = newLines.map(l => l.trim()).filter(Boolean).join('\n');
       setRawText(joined);
       try {
         localStorage.setItem(storageKey, joined);
       } catch {}
     }, [storageKey]);

     // Limpa o rascunho após inclusão bem-sucedida
     const clearDraft = useCallback(() => {
       setRawText('');
       setLines(['']);
       try {
         localStorage.removeItem(storageKey);
       } catch {}
     }, [storageKey]);

     return {
       rawText,
       lines,
       isUrgent,
       setIsUrgent,
       updateRawText,
       updateLines,
       clearDraft,
       hasContent: rawText.trim().length > 0
     };
   }
   ```
