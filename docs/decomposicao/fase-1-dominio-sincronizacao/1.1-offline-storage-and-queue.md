## 2. Diretrizes de Arquitetura & Patterns

- **Storage Service (`/design-patterns`):**
  - Isolar a serialização/desserialização segura do `localStorage` em módulo autônomo.
  - Criar interface tipada para operações de sessão e cache de sala (`Room` e `LiturgicalBlock[]`).
- **Offline Queue Pattern:**
  - `offlineQueue.ts`: Gerencia itens pendentes de inclusão (`PendingAppend`) e atualizações de bloco (`PendingBlockUpdate`) com timestamp e identificação de sala.
  - Oferece métodos puros: `enqueueAppend`, `dequeueAppend`, `enqueueBlockUpdate`, `clearPendingForBlock`.
- **Fronteira Rígida de Segurança (`/secure-architecture`):**
  - A sessão armazenada (`StoredSession`) guarda estritamente: `code`, `roomId`, `role`, `sessionToken` e `expiresAt`.
  - Jamais persistir senhas em texto puro ou strings de conexão com o banco.
- **Resiliência para Android 4.4.4 KitKat (`/frontend-design` & `/prd`):**
  - Manter tratamento de `try/catch` em todas as interações com `localStorage` (dispositivos legados com modo anônimo ou storage esgotado disparam exceção fatal `QuotaExceededError`).

   ```typescript
   import { StoredSession, UserRole } from '../../types/liturgy';

   const SESSION_KEY = 'docs_church_session';
   const THREE_HOURS_MS = 3 * 60 * 60 * 1000;

   export function getStoredSession(): StoredSession | null {
     try {
       const raw = localStorage.getItem(SESSION_KEY);
       if (!raw) return null;
       const parsed: StoredSession = JSON.parse(raw);
       if (Date.now() > parsed.expiresAt) {
         localStorage.removeItem(SESSION_KEY);
         return null;
       }
       return parsed;
     } catch {
       return null;
     }
   }

   export function saveSession(session: Omit<StoredSession, 'expiresAt'>): StoredSession {
     const complete: StoredSession = {
       ...session,
       expiresAt: Date.now() + THREE_HOURS_MS
     };
     try {
       localStorage.setItem(SESSION_KEY, JSON.stringify(complete));
     } catch {}
     return complete;
   }

   export function clearSession(): void {
     try {
       localStorage.removeItem(SESSION_KEY);
     } catch {}
   }
   ```
