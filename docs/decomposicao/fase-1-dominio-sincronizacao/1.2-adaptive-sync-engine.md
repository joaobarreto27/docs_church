## 1. Diagnóstico e Problemas Atuais

No arquivo `RoomContext.tsx`, o ciclo de vida do polling para sincronizar o culto ao vivo possui diversos timers e listeners registrados diretamente no corpo do componente:
1. **Lógica de Fast Sync vs Slow Sync:** Quando o obreiro ou pastor interage com a tela, o app entra em modo de sincronização rápida (2.5 minutos de ciclo a cada 3-5s). Fora desse período, volta para o modo espaçado (15s a 30s) para não sobrecarregar as cotas serverless do Neon nem acionar defesas WAF.
2. **Cold Start do Neon:** Verificação de atraso superior a 2.5s na primeira resposta para exibir o alerta educativo: *"Conectando à igreja... Por favor aguarde uns segundos"*.
3. **Sincronização Inter-Abas:** Escuta de `storage` event (`docs_church_intertab_sync`) para atualizar instantaneamente outras abas abertas no mesmo navegador sem disparar requisições HTTP adicionais.
4. **Acoplamento:** Toda essa inteligência de rede está misturada com a renderização e o estado da UI no `RoomContext.tsx`.

---

## 2. Diretrizes de Arquitetura & Patterns

- **Custom Hook Pattern (`/design-patterns`):**
  - Criar `useAdaptiveSync.ts` que recebe `roomId`, `onSync`, `onError` e expõe `{ isFastSync, isColdStarting, isConnected, triggerFastSync }`.
- **Consciência de WAF e Dispositivos Legados (`/secure-architecture` - Lei 6):**
  - O polling DEVE respeitar o intervalo mínimo de segurança quando em background (`document.hidden`).
  - Implementar backoff exponencial (1s → 2s → 5s → 15s) caso ocorram quedas de conexão, evitando banimento por firewall da Vercel ou Cloudflare.
- **Resiliência Android 4.4.4 KitKat (`/frontend-design` & `/prd`):**
  - Evitar o uso de `BroadcastChannel` nativo sem fallback para evento `window.addEventListener('storage', ...)` (KitKat não possui `BroadcastChannel`).
- **Cold Start do Neon (`/prd` - Restrição 3):**
  - Acionar `isColdStarting` se a primeira carga do banco demorar mais que 2.000ms.

   ```typescript
   const BROADCAST_SYNC_KEY = 'docs_church_intertab_sync';

   export function broadcastLocalChange(roomId: string): void {
     try {
       localStorage.setItem(BROADCAST_SYNC_KEY, JSON.stringify({ roomId, timestamp: Date.now() }));
     } catch {}
   }

   export function subscribeToIntertabChanges(roomId: string, onChange: () => void): () => void {
     const handleStorage = (e: StorageEvent) => {
       if (e.key === BROADCAST_SYNC_KEY && e.newValue) {
         try {
           const payload = JSON.parse(e.newValue);
           if (payload.roomId === roomId) {
             onChange();
           }
         } catch {}
       }
     };

     window.addEventListener('storage', handleStorage);
     return () => window.removeEventListener('storage', handleStorage);
   }
   ```
