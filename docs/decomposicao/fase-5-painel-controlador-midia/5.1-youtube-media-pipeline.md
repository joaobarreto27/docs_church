## 1. Diagnóstico e Problemas Atuais

No `ControladorPanel.tsx`, a equipe de transmissão ao vivo do YouTube possui uma ferramenta para capturar prints de pedidos de oração enviados no chat da transmissão:
1. **Compressor Canvas Embutido:** A função `compressImageFile(file: File | Blob)` manipula diretamente elementos `<canvas>` para redimensionar prints para no máximo 600px de largura e qualidade JPEG 0.65, gerando Data URLs em Base64.
2. **Listener de Colar da Área de Transferência:** `handlePasteEvent` escuta comandos `Ctrl+V` / `Cmd+V` para capturar capturas de tela imediatamente.
3. **Formulário de Inclusão Rápida:** Campo de texto complementar e botão para enviar o pedido direto para o bloco `prayers_youtube`.
4. **Problemas:** A manipulação de Canvas e FileReader mistura lógica de processamento de imagem pesada com a renderização da mesa de controle.

## 2. Diretrizes de Arquitetura & Patterns

- **Custom Hook Pattern (`/design-patterns`):**
  - Criar `useYoutubeCapture.ts` encapsulando:
    - `youtubeText`, `youtubeImageBase64`, `isCompressing`.
    - `handleFileSelect`, `handlePasteEvent`, `clearCapture`, `submitYoutubePrayer`.
- **Strategy de Processamento de Imagem:**
  - `canvasCompressor.ts`: Função pura que recebe `File | Blob` e retorna `Promise<string>` comprimida sem dependências do React.
- **Consciência de WAF e Payload (`/secure-architecture` - Leis 2 e 6):**
  - Garantir que imagens comprimidas não excedam 150KB para evitar rejeição de payload (`413 Payload Too Large`) nas serverless functions da Vercel.

1. **CRIAÇÃO DE `canvasCompressor.ts`:**
   ```typescript
   export function compressImageFile(file: File | Blob, maxWidth = 600, quality = 0.65): Promise<string> {
     return new Promise((resolve, reject) => {
       const reader = new FileReader();
       reader.onload = (e) => {
         const img = new Image();
         img.onload = () => {
           const canvas = document.createElement('canvas');
           const scale = Math.min(1, maxWidth / img.width);
           canvas.width = img.width * scale;
           canvas.height = img.height * scale;
           const ctx = canvas.getContext('2d');
           if (!ctx) return reject(new Error('Canvas context unavailable'));
           ctx.drawImage(img, 0, 0, canvas.width, canvas.height);
           resolve(canvas.toDataURL('image/jpeg', quality));
         };
         img.onerror = () => reject(new Error('Falha ao carregar imagem'));
         img.src = e.target?.result as string;
       };
       reader.onerror = () => reject(new Error('Falha ao ler arquivo'));
       reader.readAsDataURL(file);
     });
   }
   ```
