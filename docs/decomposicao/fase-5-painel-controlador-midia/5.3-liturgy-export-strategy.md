- **Patterns:** Strategy Pattern, Factory Pattern, Composition

> ⚠️ **REGRA INVIOLÁVEL: PRESERVAÇÃO INTEGRAL DE REGRAS DE NEGÓCIO**  
> Esta subfase é estritamente de refatoração estrutural. Nenhuma regra de exportação litúrgica (compatibilidade com software Holyrics para projeção de igreja, formatação com negritos e cabeçalho solene para WhatsApp, e agrupamento por abas de visitantes, orações e conjuntos) pode ser alterada, simplificada ou perdida.

---

## 1. Diagnóstico e Problemas Atuais

A geração de resumos textuais do culto para cópia na área de transferência e envio para os grupos da igreja está dividida entre `src/utils/liturgyExport.ts` e o modal interno de `ControladorPanel.tsx`:
1. **Lógica de Formatação Mista:** Concatenação manual de strings com condicionais `if/else` espalhados para adicionar asteriscos do WhatsApp ou formatação de projeção para o Holyrics.
2. **Abas de Visualização no Modal:** O modal permite alternar entre Todas, Visitantes, Orações, YouTube, Conjuntos e Oportunidades, mas a filtragem e a montagem do texto estão acopladas à interface.
3. **Dificuldade de Extensão:** Adicionar um novo formato de exportação (ex: JSON para arquivo de backup ou PDF) exigiria alterar o componente visual do controlador.

---

## 2. Diretrizes de Arquitetura & Patterns

- **Strategy Pattern (`/design-patterns`):**
  - Definir a interface `LiturgyExportStrategy`:
    ```typescript
    export interface LiturgyExportStrategy {
      format(room: Room, blocks: LiturgicalBlock[], tab: string): string;
    }
    ```
  - Implementar estratégias especializadas em `src/services/export/strategies/`:
    - `HolyricsExportStrategy.ts`: Estrutura compatível com o software de projeção de igreja Holyrics.
    - `WhatsAppExportStrategy.ts`: Formatação com emojis e negrito (`*`) para compartilhamento com a liderança.
    - `PlainTextExportStrategy.ts`: Texto limpo para impressão rápida ou anotação.
- **Factory Pattern:**
  - `exportStrategyFactory.ts` seleciona a estratégia correta com base no formato escolhido.
- **Composition Pattern:**
  - `LiturgyExportModal.tsx`: Componente de modal isolado que consome as estratégias de exportação e gerencia a cópia para a área de transferência com feedback visual.

## 3. Requisitos Determinísticos Passo a Passo

Atue como um **Engenheiro de Software Staff e Especialista em Padrões de Projeto e Formatação de Dados**.

### CONTEXTO:
Ao final do culto (ou durante a transmissão), a equipe precisa copiar os visitantes para os avisos da igreja ou salvar a liturgia no sistema de projeção Holyrics.

### OBJETIVO:
Criar a arquitetura Strategy para exportação de dados e extrair o modal `LiturgyExportModal.tsx`.

### DIRETRIZES DE ARQUITETURA:
1. Criar pasta `src/services/export/strategies/`.
2. Criar `src/services/export/types.ts`:
   - Interface `LiturgyExportStrategy`.
3. Criar `HolyricsExportStrategy.ts`, `WhatsAppExportStrategy.ts` e `PlainTextExportStrategy.ts`.
4. Criar `src/services/export/exportFactory.ts`.
5. Criar `src/components/controlador/modals/LiturgyExportModal.tsx`.
6. Criar `src/services/export/index.ts` com Barrel Export.

### REQUISITOS DETERMINÍSTICOS:

1. **INTERFACE `types.ts`:**
   ```typescript
   import { Room, LiturgicalBlock } from '../../types/liturgy';

   export type ExportFormat = 'whatsapp' | 'holyrics' | 'plain';
   export type ExportSection = 'all' | 'visitors' | 'prayers' | 'youtube' | 'choirs' | 'opps';

   export interface LiturgyExportStrategy {
     format(room: Room, blocks: LiturgicalBlock[], section: ExportSection): string;
   }
   ```

2. **CRIAÇÃO DE `WhatsAppExportStrategy.ts`:**
   - Adiciona cabeçalho solene da igreja, título, data e listas formatadas com `*` para negrito no WhatsApp.

3. **CRIAÇÃO DE `HolyricsExportStrategy.ts`:**
   - Prepara quebras de linha ideais para leitura em telão/projetor.

4. **CRIAÇÃO DE `LiturgyExportModal.tsx`:**
   - Abas para escolher o bloco (`all`, `visitors`, `prayers`, etc.).
   - Seletor de formato (WhatsApp / Holyrics / Texto Puro).
   - Área de preview e botão "Copiar Liturgia" com indicação de copiado.
