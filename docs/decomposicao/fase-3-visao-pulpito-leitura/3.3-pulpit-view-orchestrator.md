## 1. Diagnóstico e Problemas Atuais

O arquivo `src/components/pastor/PulpitView.tsx` é o segundo maior arquivo do repositório (1.535 linhas):
1. **Acúmulo Excessivo de Responsabilidades:** Contém lógica de particionamento, detecção de smartphone, cálculo de colunas, gerenciamento de abas mobile, renderização de folhas em paisagem, controles de zoom e modais de saída.
2. **Duplicação de Estruturas:** As listas de visitantes, pedidos de oração e oportunidades são renderizadas em duas seções distintas do código (uma para celular e outra para tablet).
3. **Dificuldade de Inspeção:** A enorme quantidade de JSX impede que manutenções no púlpito sejam feitas com rapidez durante testes de pré-culto.

---

## 2. Diretrizes de Arquitetura & Patterns

- **Single Responsibility (`/design-patterns`):**
  - O arquivo master `PulpitView.tsx` passa a ser unicamente um **orquestrador responsivo**: consome o estado do culto (`useRoom()`), delega para os hooks de layout e alterna declarativamente entre `<PulpitMobileView />` e `<PulpitLandscapeSpread />`.
- **Composition Pattern:**
  - Inclusão harmoniosa do `<AlertBanner />` no topo e dos controles de acessibilidade.
- **Resiliência Offline (`/secure-architecture` & `/prd`):**
  - Caso o Wi-Fi oscile, o orquestrador não exibe telas em branco e mantém a exibição contínua a partir do cache local.

   ```typescript
   import React, { useState } from 'react';
   import { useRoom } from '../../context/RoomContext';
   import { usePulpitLayout, usePulpitPagination } from './hooks';
   import { 
     AlertBanner, 
     PulpitHeader, 
     PulpitLandscapeSpread, 
     PulpitMobileView, 
     PulpitZoomControls 
   } from './components';

   export const PulpitView: React.FC = () => {
     const { room, blocks, isConnected, isColdStarting } = useRoom();
     const { fontScale, isMobilePhone, changeFontScale, resetFontScale } = usePulpitLayout();
     const { currentPage, totalPages, nextPage, prevPage } = usePulpitPagination();
     const [showLeaveModal, setShowLeaveModal] = useState(false);

     if (!room) return null;

     return (
       <div className="h-full w-full flex flex-col bg-[#FAF8F5] select-none overflow-hidden relative min-h-0">
         <AlertBanner alert={room.active_alert} />
         
         <PulpitHeader 
           title={room.title}
           isConnected={isConnected}
           isColdStarting={isColdStarting}
           onOpenLeave={() => setShowLeaveModal(true)}
         />

         <main className="flex-1 overflow-hidden h-full max-h-full min-h-0 flex flex-col">
           {isMobilePhone ? (
             <PulpitMobileView room={room} blocks={blocks} fontScale={fontScale} />
           ) : (
             <PulpitLandscapeSpread 
               room={room} 
               blocks={blocks} 
               fontScale={fontScale} 
               currentPage={currentPage}
               onNextPage={nextPage}
               onPrevPage={prevPage}
             />
           )}
         </main>

         <PulpitZoomControls 
           fontScale={fontScale} 
           onChangeScale={changeFontScale} 
           onReset={resetFontScale} 
         />
       </div>
     );
   };
   ```
