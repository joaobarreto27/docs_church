## 1. Diagnóstico e Problemas Atuais

O arquivo `PulpitView.tsx` possui implementações inline de regras críticas de dimensionamento para o púlpito:
1. **Detecção de Smartphone vs Tablet:** Função `isSmartphoneDevice()` baseada em User-Agent e dimensões de tela (`window.innerWidth` e `window.innerHeight`).
2. **Particionamento Sequencial de Colunas:** Função `partitionSequentialColumns<T>(items, capacity)` para distribuir visitantes e pedidos de oração entre colunas sem estourar a altura da tela.
3. **Escala de Fonte Configurável:** Persistência no `localStorage` de zoom de fonte (`fontScale`: 0.85 a 1.45) para pastores com dificuldades visuais.
4. **Zero Scroll Vertical:** Cálculo de capacidade de itens por folha para respeitar a **Restrição Inviolável #2** do PRD (modo paisagem com duas folhas lado a lado, estilo livro aberto, sem barra de rolagem).

## 2. Diretrizes de Arquitetura & Patterns

- **Pure Functions (`/design-patterns`):**
  - Isolar `partitionSequentialColumns` em `src/components/pastor/utils/pulpitPartitioning.ts` como função pura e determinística, 100% testável.
- **Custom Hook Pattern:**
  - `usePulpitLayout.ts`: Encapsula `fontScale`, `increaseFont`, `decreaseFont`, `resetFont`, `isMobilePhone`, `sheetLayout` e detecção de orientação de tela (`landscape` vs `portrait`).
- **Resiliência Android 4.4.4 KitKat (`/frontend-design` & `/prd`):**
  - Manter fallbacks seguros para detecção de orientação (`window.orientation` e resize clássico, pois `screen.orientation` moderno não existe em WebViews antigas).

### REQUISITOS DETERMINÍSTICOS:

1. **CRIAÇÃO DE `pulpitPartitioning.ts`:**
   ```typescript
   export function partitionSequentialColumns<T>(items: T[], capacity: number = 10): { col1: T[]; col2: T[] } {
     if (!items || items.length === 0) return { col1: [], col2: [] };
     const mid = Math.ceil(items.length / 2);
     return {
       col1: items.slice(0, mid),
       col2: items.slice(mid)
     };
   }
   ```

2. **CRIAÇÃO DE `usePulpitLayout.ts`:**
   - Detectar `isMobilePhone` respeitando Android KitKat.
   - Controlar escala de fonte com multiplicador CSS em rem.

3. **CRIAÇÃO DE `usePulpitPagination.ts`:**
   - Fornecer navegação por toque nas bordas da tela ou setas do teclado.
